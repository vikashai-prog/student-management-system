# 🎓 Student Management System with AI Chatbot  
*Because managing students should be smart and fast!*

Managing student records manually can be time-consuming and inefficient. To solve this, we built a **Student Management System** that allows users to **add, update, delete, and view student data** easily.

To make the system more intelligent, we integrated an **AI Chatbot 🤖** that can answer queries like total students, list of students, and searching a student — making interaction faster and user-friendly.

---

## 🔍 Project Overview

This system helps in:

- Managing student records efficiently  
- Avoiding duplicate entries  
- Searching students instantly  
- Interacting with data using chatbot  
- Viewing all records in a clean UI
